.. _MargoExercises:

Margo exercises
===============

This section contains an exercise meant to accompany Mochi tutorials.
These tutorials focus on using the C language, with the Margo library.
They revolve around the development of a phonebook data service,
i.e. a service that associates names (null-terminated strings) with
phone numbers (which will be represented as :code:`uint64_t` values).
